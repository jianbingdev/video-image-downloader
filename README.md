# 视频图片下载器

一个 Edge 扩展（Manifest V3），把「抖音视频下载」和「全网页图片下载」两个功能装在同一个扩展里。

- **视频**：在抖音 / 千川页面把鼠标移到视频上，右上角浮出下载按钮；按作者、描述、分辨率、vid 组合文件名，可选子目录
- **图片**：任意网页右下角常驻一个下载按钮，鼠标指着哪张图就下哪张；也能一键下载本页全部图片

## 安装

1. 下载本仓库（`Code → Download ZIP`，或 `git clone`）
2. 打开 `edge://extensions/`，打开「开发人员模式」
3. 点「加载解压缩的扩展」，选中**包含 `manifest.json` 的那一层目录**

Chrome 同样可用，步骤一致。

## 使用

**下载视频**：进入抖音视频页 → 鼠标移到视频上 → 点右上角浮出的下载按钮。
遇到「弹窗播放」的视频（千川后台常见）也能下，会从资源请求里翻真实地址。

**下载图片**：
- 单张：把鼠标移到图片上，再点页面上的「下载图片」按钮
- 全部：点扩展图标 → 「下载本页全部图片」

按钮位置可以在弹窗里改（九宫格锚点 + 距屏幕边缘的距离），设置即时生效。

**视频设置**：弹窗底部「视频下载设置」进设置页，可改文件名模板、画质偏好、下载子目录、下载提示。

## 已知限制

- **必须用解压目录加载**，不走商店。浏览器不会自动更新，换版本要手动替换文件后点一次「重新加载」。
- 视频下载依赖抖音的页面结构与接口，平台改版可能失效。
- 图片「下载全部」单次上限 100 张。
- 抖音 CDN 有防盗链，部分视频需要 Referer 才能取到，扩展为此做了三层降级，仍可能有个别视频取不到直链。

## 目录说明

| 路径 | 说明 |
|---|---|
| `manifest.json` | 扩展清单 |
| `service-worker.js` | 后台入口，把两套后台脚本串起来 |
| `background.js` | 视频下载核心（打包产物，压缩后约 64KB） |
| `content-scripts/` | 抖音 / 千川页面的内容脚本（打包产物） |
| `fetcher.js` | 注入页面主世界，负责带 Referer 的请求 |
| `offscreen.js` / `offscreen.html` | MV3 offscreen 文档，视频下载的第二通道 |
| `imgdl/` | 图片下载器（手写源码：内容脚本、后台、弹窗） |
| `chunks/` `assets/` | 打包产物的依赖与样式 |
| `_locales/` | 多语言文案 |

`background.js` 和 `content-scripts/content.js` 是压缩过的打包产物，直接读会很痛苦；对应的 WXT 工程源码当前不在本仓库内。
